# Chrome 扩展安装

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `browser-extension` 文件夹。
5. 固定“招聘 Agent 采集与受控执行器”，并保持本地后端与已登录的 BOSS 页面打开。

扩展默认只读取当前 BOSS 页面。只有在控制台点击“批量索要简历”时，才会对未读/红点会话发送固定话术“方便发一份你的简历过来吗？”。约面、拒绝、自由回复和草稿批准都不会自动执行平台发送。

附件简历处理：

- 有 PDF 直链时，扩展会尝试下载并回传给本地后端解析。
- 没有直链但可以预览时，扩展会点击预览并提取预览层文本，回传给本地后端生成简历记录、候选人画像和岗位评分。
