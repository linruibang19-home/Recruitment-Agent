# 05 Risk Control

## 风险结论

项目涉及浏览器自动化、消息发送、简历处理和个人信息存储，存在平台风控和隐私合规风险。项目目标应定义为合规招聘辅助工具，而不是绕过平台检测的批量脚本。

## 平台风险

高风险动作：

- 高频主动打招呼。
- 高频重复话术。
- 异常时间段集中操作。
- 验证码或账号异常后继续操作。
- 自动处理敏感沟通。
- 重复触达同一候选人。

控制策略：

1. 默认每日主动触达上限为 50。
2. 设置每小时上限，默认不超过 10。
3. 工作时间窗口运行，非必要不深夜触达。
4. 不强制用完每日额度。
5. 所有候选人本地去重。
6. 遇到验证码、登录失效、账号异常、连续失败立即停机。
7. 不实现验证码绕过、指纹伪装或平台限制绕过。

## 自动化动作分级

### Level 0: 只读动作

可默认自动：

- 打开页面
- 读取列表
- 读取聊天
- 读取候选人信息
- 识别附件
- 截图

### Level 1: 本地处理动作

可默认自动：

- 下载或读取已授权可见附件
- PDF 解析
- OCR
- LLM 画像
- 评分
- 入库
- 生成草稿

### Level 2: 低风险写动作

可配置自动，MVP 默认进入待确认：

- 索要简历
- 简短打招呼
- 同意接收候选人主动发来的附件简历

### Level 3: 高风险写动作

必须人工确认：

- 约面试
- 薪资讨论
- 加微信/电话
- 拒绝候选人
- 录用倾向表达
- 任何承诺性质内容

## 消息发送限频

默认配置：

```yaml
automation:
  max_daily_greetings: 50
  max_hourly_greetings: 10
  min_interval_seconds: 60
  max_interval_seconds: 360
  stop_after_send_failures: 3
```

间隔策略：

- 使用随机间隔用于节流和降低打扰。
- 不以绕过平台风控为目的。
- 每次发送前检查本地 quota。
- 发送失败不重试超过配置次数。

## 隐私和数据安全

简历和聊天记录属于敏感个人信息。

必须做到：

1. `.env` 不提交。
2. 数据库文件、简历附件、截图不提交。
3. LLM 调用前可配置脱敏。
4. 简历文件保存在本地受控目录。
5. 前端展示联系方式时可做遮罩。
6. 记录谁在何时执行了什么动作。
7. 支持删除候选人数据。

## 异常停机条件

出现以下情况立即停止自动化任务：

- 页面出现验证码。
- 页面提示登录失效。
- 页面提示账号异常。
- 页面结构发生明显变化。
- 连续 3 次发送失败。
- 连续 3 次附件读取失败。
- 用户手动点击停止。
- 当前时间不在允许运行窗口。

## 审计要求

每次自动化动作记录：

- 时间
- 动作类型
- 页面 URL
- 候选人 ID
- 输入参数
- 执行结果
- 错误信息
- 截图路径
- workflow run ID
