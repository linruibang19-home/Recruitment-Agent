# 01 Requirements

## 项目目标

构建一个本地可视化招聘 Agent 系统，辅助在 BOSS 直聘企业端完成候选人沟通、简历收集、简历解析、候选人画像、岗位匹配评分、每日推荐和约面话术生成。

系统定位是招聘辅助工具，不是无约束批量脚本。自动化能力应服务于减少重复劳动、提升筛选效率、形成可追踪候选人库。

## 用户场景

### 场景 A: 沟通页候选人处理

入口页面：`https://www.zhipin.com/web/chat/index`

目标能力：

1. 复用用户已登录的浏览器会话。
2. 读取左侧沟通列表。
3. 依次打开求职者聊天页面。
4. 读取候选人顶部信息和聊天上下文。
5. 判断候选人是否已经发送简历。
6. 未发送简历时，生成索要简历话术。
7. 候选人请求发送附件简历时，自动同意接收。
8. 发现 PDF 附件时，点击预览或下载。
9. 解析 PDF 文本；无法提取文本时进入 OCR 或多模态 LLM 解析。
10. 抽取结构化候选人信息并入库。
11. 生成候选人画像、岗位匹配结果和综合评分。
12. 每天推荐若干优秀候选人，并生成约面回复语。

### 场景 B: 推荐牛人主动触达

入口页面：`https://www.zhipin.com/web/chat/recommend`

目标能力：

1. 根据岗位配置选择城市、经验、学历、薪资、求职意向等筛选条件。
2. 读取推荐牛人卡片信息。
3. 本地去重，避免重复打招呼。
4. 根据岗位关键词和候选人卡片做初筛。
5. 生成简短招呼语，核心目的是索要简历。
6. 控制主动触达额度，默认每天最多 50 人。
7. 记录发送状态、回复状态和后续处理状态。

### 场景 C: 每日推荐

目标能力：

1. 每天汇总新增或更新候选人。
2. 按岗位匹配度、学历、学校、项目经历、技能栈、沟通质量、风险点排序。
3. 输出 Top N 推荐名单。
4. 给出推荐理由、风险说明和建议下一步动作。
5. 对高分候选人生成约面话术。

## 候选人结构化字段

基础字段：

- BOSS 候选人 ID 或本地唯一 ID
- 姓名
- 年龄
- 学历
- 学校
- 专业
- 毕业年份
- 城市
- 求职意向
- 期望薪资
- 可到岗时间

招聘判断字段：

- 校招或社招
- 工作年限
- 实习经历
- 项目经历
- 技能栈
- 证书/竞赛/论文/开源经历
- 岗位关键词命中情况
- 简历亮点
- 风险点
- 面试建议

流程字段：

- 是否已打招呼
- 是否已回复
- 是否已索要简历
- 是否已收到简历
- 是否已解析简历
- 是否已评分
- 是否已推荐
- 是否已约面
- 是否需要人工处理

## 自动化边界

MVP 默认自动：

- 页面读取
- 候选人信息抽取
- 附件检测
- 简历解析
- 入库
- 打分
- 推荐
- 回复草稿生成

MVP 默认人工确认：

- 主动打招呼发送
- 索要简历消息发送
- 约面消息发送
- 薪资、微信、电话、拒绝类回复

后续可以通过配置逐步开启低风险自动发送。
