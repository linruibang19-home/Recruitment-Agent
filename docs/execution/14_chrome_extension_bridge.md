# Chrome 扩展采集闭环

## 目标

使用用户正常登录的 Chrome 标签页读取 BOSS 直聘沟通页和推荐牛人页，替代会被页面关闭的
Playwright/CDP 登录方案。扩展只执行页面读取和附件下载，不填写输入框、不点击发送。

## 组件

- `browser-extension/`：Manifest V3 扩展、页面解析器、后台任务轮询和 PDF 回传。
- `/api/extension/heartbeat`：扩展在线状态和当前页面心跳。
- `/api/extension/commands`：控制台创建只读采集任务。
- `/api/extension/commands/next`：扩展领取持久化任务。
- `/api/extension/commands/{id}/complete`：回传采集结果并触发入库。
- `extension_sessions`：扩展在线状态。
- `extension_commands`：任务状态、输入和结果。

## 使用步骤

1. 运行 `scripts/start.ps1`。
2. 打开 `chrome://extensions` 并开启开发者模式。
3. 选择“加载已解压的扩展程序”，加载项目的 `browser-extension` 文件夹。
4. 打开普通 Chrome，登录 BOSS 直聘。
5. 在工作台“沟通采集”中确认扩展已连接。
6. 沟通页可执行“扫描沟通列表”；也可以执行“批量读取聊天”，由扩展逐个打开左侧可见会话并读取详情。
7. 选中单个候选人后可执行“读取当前聊天”，用于补采或排查某一位候选人。
8. 推荐牛人页在工作台填写岗位筛选条件后提交扫描任务。
9. 在“候选人库”和“待确认”中查看入库资料、索要简历草稿和附件记录。

## 数据处理

- 沟通列表按 BOSS 链接或页面文本生成稳定候选人标识。
- `scan_chat_details` 会对左侧可见会话按索引逐个点击，等待聊天详情刷新后读取消息和附件。
- 聊天消息按候选人、方向、内容和时间生成哈希，重复扫描不会重复入库。
- 未检测到简历时生成 `request_resume_chat` 草稿，`auto_send=false`。
- 检测到附件时生成 `resume_attachment_detected` 待确认项。
- PDF 直链可下载时自动调用现有简历上传接口，继续执行文本提取、OCR、画像和岗位评分。
- 推荐牛人结果沿用岗位关键词筛选、重复检查和每日 50 条草稿额度。

## 安全边界

- 不实现验证码绕过、反检测或风控规避。
- 不自动发送打招呼、索要简历或约面消息。
- 草稿批准只更新本地状态，不执行平台写操作。
- 页面结构变化会导致解析任务失败，失败信息保留在扩展任务和审计日志中。

## 验证

- Python 测试覆盖聊天、附件和牛人卡片 DOM 解析。
- PostgreSQL 闭环验证覆盖心跳、任务排队、领取、结果回传、候选人和消息入库、草稿生成。
- 前端生产构建和本地页面交互通过 Playwright 验证。
